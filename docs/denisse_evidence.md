- Whether a learned routing lesson changes behaviour against the same prompts with learning off.
- By suite area: multi-step requests through the planner, `look_at_this` called when pointed at text and left alone otherwise, fixture-vault search and study mode.
- (Voice was not measured in this run.)

Not measured here, so not claimed:

- Accuracy on open-ended real use. The suites are small and hand-written; a pass means these checks held, not that every reply is good.
- Real-room speech recognition. Synthetic speech is cleaner than a microphone.
- End-to-end voice latency (wake word to spoken reply), except as far as the voice turn stages section above has numbers from real logged turns.
- The `live` eval condition (replayed real history) is excluded because it uses private conversation data; it runs nightly outside this pack.
- Reply quality beyond the deterministic checks: no LLM judge is used.
- Desktop UI behaviour; that is `scripts/smoke_pet_chat.py`, which needs an interactive desktop.

Reply text is deliberately not stored: the results file is public, and some suite cases answer from personal facts. Failure reasons are kept with file paths redacted.

## Reproduce

Windows, Python 3.12, [Ollama](https://ollama.com) running with the model pulled:

```powershell
ollama pull llama3.1:8b
.venv\Scripts\python.exe demo\run_demo.py --rounds 3
# fewer rounds, or without parts:  --rounds 1 --skip voice learning
# voice models elsewhere:          --models-dir C:\path\to\models
.venv\Scripts\python.exe demo\report.py            # re-render this page from the latest results
.venv\Scripts\python.exe scripts\run_checks.py     # offline regression gate, no model needed
```

Each part can also be run alone: `demo/suite_rounds.py`, `scripts/eval_dialogue_reliability.py`, `scripts/eval_standing_instructions.py`, `scripts/eval_adaptive_brain.py`, `scripts/eval_local_voice.py`, `demo/voice_stages.py`.
